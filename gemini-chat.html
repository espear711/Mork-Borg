Random Tables

Define tables with a !Command trigger. When !Command appears in any message (user or AI), a random result is rolled and appended after the command.

AI Pipeline

Add passes between user input and final output. Each pass sends the user message + all prior pass results to the AI with its own instructions. Use toggles to control what context each pass sees. !Commands are processed after each pass.
